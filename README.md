# Oqu Analytics

**Әдіскерге арналған оқу нәтижелерін талдау платформасы.** Тест нәтижелерін тақырып бойынша талдайды, қиын тақырыптарды табады, оқулықтарды мектеп құрамына түзетіп салыстырады және оқу сағаттарын бөлуге дәлелді ұсыныс береді.

> Zhambyl Hub Hackathon 2026 · Кейс №1 «Data-Driven Curriculum»

**Демо:** https://baibek.github.io/oqu-analytics/ — тіркелусіз ашылады, қазақ және орыс тілінде.

## Не көруге болады

Жоғарғы панельде төрт таңдау бар: **Пән → Параллель (поток) → Мектеп → Сынып**.

- **Бүкіл облыс** — барлық мектептің нәтижесі, оқулық салыстыруы және сағат ұсынысы.
- **Бір мектеп немесе бір сынып (мысалы, №5 мектеп, 9Ә)** — тақырыптар сол мектептің/сыныптың өз нәтижесімен есептеліп, әр тақырыпта облыс деңгейімен салыстырылады; сағат ұсынысы сол сыныптың әлсіз тақырыптарына бейімделеді. Оқулық салыстыруы мен «қосымша сағат қаншалықты көмектеседі» деген баға бір сыныптың 15–30 оқушысымен сенімді болмайды, сондықтан олар облыс деректерінен алынады және бұл интерфейсте ашық жазылған.

Демода 4 пән, 11 курс бар: алгебра, геометрия, физика (7–9-сыныптар), химия (8–9-сыныптар).

## Кейстің төрт талабы

| Талап | Не жасалған | Экран |
|---|---|---|
| Тест нәтижесін тақырып бойынша талдау | Әр тақырыптың меңгеру үлесі 95% сенім аралығымен, қала/ауыл бөлінісі, сыныптар арасындағы шашырау | Тақырыптар |
| Қиын бөлімдерді анықтау | «Қиын / назарда / қалыпты» мәртебесі, шекке жақын болса «≈» белгісі; себебі тірек тақырыпта болса, соны көрсетеді | Тақырыптар, Шолу |
| Оқулықтарды салыстыру | Қарапайым айырма мен түзетілген әсер қатар; бастапқы деңгейге, қала/ауылға, оқыту тіліне түзету; мектеп бойынша кластерлік қателер; бөлімдер бойынша кесте | Оқулықтар |
| Сағатты бөлу ұсынысы | Жылдық сағат сақталады, шек ±30%, әр жолда «неге?» дәлелі, болжам ± қатемен, қолмен өзгерту, құлыптау, нұсқаны сақтау, CSV және PDF | Сағаттар |

## Неге бұл адал талдау

- **Оқулық салыстыруы мектептерді емес, оқулықты салыстырады.** Демо дерегінде ауыл мектептері B оқулығын жиі таңдайды. Орташа балл бойынша B оқулығы 2 балл төмен көрінеді, ал бастапқы деңгейге түзеткенде ол 5 балл жоғары. Жүйе мұндай жағдайда ескерту шығарады.
- **Дерек аз болса, қорытынды жасалмайды.** Тақырыпқа 30-дан аз оқушы немесе 5-тен аз сынып тобы болса, «дерек жеткіліксіз» деп жазылады. Бастапқы деңгей жоқ болса, оқулық айырмасы «дәлелденбеген» деп көрсетіледі.
- **Сағат тек көмектесетін жерге қосылады.** Тақырып әлсіз, бірақ сағат қосудың пайдасына дәлел жоқ болса, жүйе сағат қоспайды және мәселе әдістемеде немесе тірек тақырыпта болуы мүмкін екенін айтады.
- **Әдіс белгілі жауапта тексерілген.** Демо дерегіне «дұрыс жауаптар» әдейі салынған (`src/lib/generate.ts`, `TRUTH`), ал тесттер әдістердің оларды табатынын тексереді: қате бағытталған қарапайым салыстыру, жоқ әсерді «дәлелденбеген» деп тану, сағатқа сезімтал тақырыптар, жалған дабыл жиілігі ≈5%.

## Демо дерегі

Дерек **синтетикалық** және интерфейсте солай белгіленген: әр курста 64 ойдан алынған мектеп, қалалық мектептерде 2–3 сынып (А, Ә, Б), ауылдықтарда 1 сынып, барлығы шамамен 2 000 оқушы. Тақырыптар мектеп курсының мазмұнына сай, сағат бөлінісі — үлгі. «Дұрыс жауаптар» 8-сынып физикасына салынған. Оқулықтар әдейі «Оқулық A / B / C / D» деп аталған: синтетикалық балмен нақты баспаның оқулығын «нашар» деп көрсетуге болмайды. Оқулық D-де тек 3 мектеп бар, сондықтан ол «дерек жеткіліксіз» деп көрсетіледі.

## Өз дерегіңізді жүктеу

«Дерек» бетінен CSV жүктеңіз (үтір немесе нүктелі үтір, UTF-8). Файл браузерде өңделеді және ешқайда жіберілмейді. Үлгілерді сол беттен жүктеп алуға болады.

`results.csv` — бір жол: бір оқушының бір тақырыптағы нәтижесі.

| Баған | Мазмұны | Міндетті |
|---|---|---|
| `subject` | Пән; бір файлда бірнеше пән болуы мүмкін | |
| `grade` | Параллель: 7, 8, 9… | |
| `class` | Сынып атауы: 8А, 8Ә… | |
| `student_id` | Оқушы коды (аты-жөні емес) | ✓ |
| `school` | Мектеп | ✓ |
| `district` | Аудан | |
| `locality` | `urban` / `rural` | |
| `language` | `kk` / `ru` — оқыту тілі | |
| `textbook` | Оқулық | ✓ |
| `baseline` | Бастапқы диагностика балы, 0–100 | оқулық салыстыруы үшін керек |
| `topic` | Тақырып | ✓ |
| `score` | Тақырып бойынша балл, 0–100 (мысалы, БЖБ) | ✓ |
| `hours` | Сыныпта тақырыпқа нақты өткізілген сағат | сағат ұсынысы үшін керек |

`curriculum.csv` (міндетті емес): `subject, grade, topic, section, planned_hours, prerequisites` (тірек тақырыптар `;` арқылы).

## Әдістеме

- **Меңгеру үлесі** — 50+ балл алғандар. «Қиын» < 50%, «назарда» 50–65%. Облыс бойынша сенім аралығы — мектептерді қайта іріктеу (кластерлік бутстрэп); бір мектеп не сынып үшін — оқушыларды қайта іріктеу, кемінде 10 оқушы.
- **Тірек тақырып** — бастапқы деңгейді шығарғаннан кейінгі корреляция; екі тақырып та әлсіз және r ≥ 0,3 болса, «ықтимал себеп» деп белгіленеді.
- **Оқулықтар** — `балл ~ оқулық + бастапқы диагностика + қала/ауыл + тіл`, стандарт қателер мектеп бойынша кластерленген (бір мектептің сыныптары тәуелсіз емес). Әсер балл мен SD бірлігінде.
- **Сағаттар** — әр тақырыпқа `сынып балы ~ ln(нақты сағат) + бастапқы деңгей + қала/ауыл`, эмпирикалық Байес арқылы сығу, жылдық соманы сақтап сағатты бір-бірлеп ең пайдалы жерге жылжыту.

**Шектеулер.** Дерек бақылаулық: мұғалім біліктілігі сияқты есепке алынбаған факторлар әсер етуі мүмкін. Халықаралық зерттеулерде оқулықтар айырмасы әдетте шағын (0,03–0,08 SD). Оқулықты ауыстыру не сағатты өзгерту шешімін алдымен бірнеше мектепте сынаған жөн.

## Іске қосу

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # статистика мен талдау тесттері
npm run build    # dist/ — кез келген статикалық хостингке
```

Стек: Vite, React, TypeScript; Inter шрифті жобаның ішінде (интернетсіз де жұмыс істейді). Бэкенд жоқ: барлық есеп браузерде, статистика сыртқы кітапханасыз жазылған (`src/lib/stats.ts`).

## Құрылым

```

src/lib/csv.ts         импорт, тексеру, экспорт
src/lib/generate.ts    демо дерегі және «дұрыс жауаптар»

src/ui/                5 экран: Шолу, Тақырыптар, Оқулықтар, Сағаттар, Дерек
tests/                 тесттер
```
